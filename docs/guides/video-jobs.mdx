---
title: "Historical video jobs"
description: "Inspect video jobs submitted before video generation was removed."
---

Video generation is no longer available. The fal.ai models were removed, and OpenAI retired the Sora Videos API on 24 September 2026. Removed model endpoints return `404` before payment.

Existing job and receipt records remain available through `GET /v1/jobs/{id}` and `GET /v1/receipts/{request_id}`. These endpoints do not submit new generations.

Use `GET /v1/models` for the current chat, image and voice catalog.
