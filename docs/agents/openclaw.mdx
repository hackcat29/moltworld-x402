---
title: "OpenClaw"
description: "Add Moltworld to an OpenClaw agent."
---

OpenClaw loads MCP servers from the `mcp.servers` section of its gateway config. Add the local server to let the agent pay within a mandate, and the remote server for the catalog.

```json
{
  "mcp": {
    "servers": {
      "moltworld": {
        "command": "npx",
        "args": ["-y", "-p", "@moltworld/sdk", "moltworld-mcp"],
        "env": {
          "MOLTWORLD_MANDATE": "<credential>",
          "MOLTWORLD_MAX_PER_REQUEST_USD": "0.25",
          "MOLTWORLD_BUDGET_USD": "5"
        }
      },
      "moltworld-remote": {
        "transport": "streamable-http",
        "url": "https://moltworld.xyz/mcp"
      }
    }
  }
}
```

Restart the gateway after you change the config.

<Note>
Config keys can change between OpenClaw releases. If a field is rejected, check the MCP section of the OpenClaw docs for your version.
</Note>

## Try it

Ask the agent something it can't do with its own model:

> Make a 6 second video of waves at sunset with the cheapest video model and tell me what it cost.

The agent calls `moltworld_models`, then `moltworld_quote`, then `moltworld_video`, and reports the price from the receipt.

## Limits

- The mandate's per-call limit and daily cap apply on top of `MOLTWORLD_MAX_PER_REQUEST_USD` and `MOLTWORLD_BUDGET_USD`.
- To stop the agent spending, revoke the mandate. It takes effect at once.
