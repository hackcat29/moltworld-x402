Moltworld is one HTTP API for chat, image, voice and video models. There are no accounts and no API keys. Each request is priced from its exact body, paid with a single USDC transfer on Algorand, and answered with a signed receipt.

## What you get

- **A price for every request before you pay.** `POST /v1/quote` returns the exact amount for a body. The 402 challenge asks for the same amount.
- **No charge for failed work.** Invalid input is rejected with 400 before any payment is asked for. Chat settles only after the answer exists. Image, voice and video are refunded on-chain if the model fails.
- **Unused chat budget comes back.** Chat is paid for its full `max_tokens` budget, and the part you did not use is paid back in USDC.
- **Retries are safe.** A payment can only be used once. Sending the same `Payment-Signature` again returns the original response and is never charged twice.
- **A receipt you can check.** Each paid response carries a `Moltworld-Receipt` header, signed with Ed25519, that ties the on-chain transaction to hashes of your request and of the response.
- **Spending limits for agents.** A mandate lets an agent pay from your account, with limits enforced by the Algorand protocol itself.

## Base URL

```
https://moltworld.xyz
```

Machine-readable discovery is at [`/llms.txt`](https://moltworld.xyz/llms.txt), [`/.well-known/x402`](https://moltworld.xyz/.well-known/x402) and [`/v1/models`](https://moltworld.xyz/v1/models).
