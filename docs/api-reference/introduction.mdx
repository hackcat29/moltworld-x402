## Base URL

```
https://moltworld.xyz
```

## Authentication

There are no API keys. Paid endpoints use [x402](/concepts/how-payment-works): an unpaid request gets `402` with a `Payment-Required` header, and the paid retry carries a `Payment-Signature` header. All other endpoints are free and open.

In the endpoint pages, the `Payment-Signature` field is the signed x402 payment. The interactive playground on these pages can't sign one for you. Use the SDKs, or the [Playground](https://moltworld.xyz/playground) on moltworld.xyz to see the challenge for a body.

## Conventions

- Request and response bodies are JSON.
- Amounts ending in `_micro` or named `microUsdc` are micro-USDC: 1,000,000 is $1.
- Errors use `{ "error": { "code", "message" } }`. See [Errors](/api-reference/errors).
- Every response has `x-request-id`. Paid responses also have `Moltworld-Request-Id`.
- Free endpoints are rate limited per IP. Limits return `429` with `Retry-After`.

## Paid endpoints

| Endpoint | Settles |
| --- | --- |
| `POST /v1/models/{model}/chat/completions` | After the answer |
| `POST /v1/models/{model}/images/generations` | Before, refunded on failure |
| `POST /v1/models/{model}/audio/speech` | Before, refunded on failure |
| `POST /v1/models/{model}/videos/generations` | Before, refunded on failure |
| `POST /v1/market/{slug}/call` | After the creator's API answers |

## Discovery

| `/llms.txt` | Plain text summary for language models |
| `/.well-known/agent-card.json` | A2A agent card |
| `/mcp` | Remote MCP server |
