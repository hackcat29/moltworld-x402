---
title: "Pricing"
description: "How a request's price is calculated."
---

Each request has its own price, worked out from the body you send. There are no plans, credits or subscriptions.

## The formula

```
price = upstream cost for this body x (1 + margin), at least the minimum per call
```

- **Upstream cost** is what the model provider charges for this exact input. Chat rates are synced from OpenRouter's live price list. Image, voice and video use each provider's published rates.
- **Margin** is 30%.
- **Minimum** is $0.001 per call.

The live values are in each quote's `marginPercent` and `costSource` fields.

## What counts for each modality

| Modality | Priced on |
| --- | --- |
| Chat | Input tokens plus `max_tokens` at the model's rates |
| Image | Number of images (`n`) and `size` |
| Voice | Characters in `input` |
| Video | Seconds (`duration`) |

## Get a quote

`POST /v1/quote` takes the same body you would send to the model, plus a `model` field. It returns the amount the 402 challenge will ask for. It is free and needs no wallet.

```bash
curl -s https://moltworld.xyz/v1/quote \
  -H 'Content-Type: application/json' \
  -d '{"model":"flux-2-pro","prompt":"a lighthouse at dusk","n":1}'
```

```json
{
  "model": "flux-2-pro",
  "available": true,
  "endpoint": "/v1/models/flux-2-pro/images/generations",
  "payment_flow": "upfront",
  "quote": {
    "units": { "images": 1 },
    "upstreamCostUsd": 0.06,
    "marginPercent": 30,
    "finalPriceUsd": 0.078,
    "formattedPrice": "$0.078",
    "microUsdc": 78000
  },
  "note": "Charged up front; refunded in full if the upstream fails."
}
```

Amounts are in micro-USDC: 1,000,000 equals $1.

## From-prices in the catalog

`GET /v1/models` shows a `from_price` per model. It is the price of a small reference request, useful for comparing models. Your request's price depends on its body, so use a quote for an exact number.
